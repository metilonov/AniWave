# AniWave 1.1 — BotHost

## Обязательные переменные `.env`

```env
BOT_TOKEN=...
ADMIN_ID=123456789
CHANNEL_ID=-1001234567890
ANIME_SEARCH_URL=https://example.com/find
```

- `ADMIN_ID` — единственный владелец/администратор AniWave.
- `CHANNEL_ID` — единственный канал, в котором бот имеет право оставаться и публиковать релизы.
- `ANIME_SEARCH_URL` — URL кнопки «Найти аниме» под каждым релизом.

## Поведение чатов

- Разрешённый `CHANNEL_ID`: получает публикации новых серий.
- Любой другой канал: AniWave покидает его при событии добавления/изменения членства или при получении channel post.
- Группы и супергруппы: бот остаётся, команды работают, чат автоматически добавляется в общую рассылку релизов.
- Личные сообщения: команды работают, после взаимодействия ЛС также становится доступным получателем рассылки.
- Если бота удалили из группы или он потерял возможность писать в чат, этот чат отключается от рассылки.

Telegram Bot API не предоставляет боту команду «показать все чаты, где ты состоишь», поэтому уже существующий старый канал без новых событий нельзя обнаружить мгновенно. Все новые добавления контролируются автоматически.

## Docker

Проект содержит `Dockerfile`. Стартовая команда внутри контейнера:

```text
python main.py
```

Для SQLite следует подключить постоянный volume к `/app/data`, иначе при пересоздании контейнера база может быть потеряна.
