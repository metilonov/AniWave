# AniWave 1.1

Telegram-бот для мониторинга аниме-релизов и рассылки новых серий.

## Что реализовано

- монитор релизов через `anicli-api` и RSS/Atom;
- AniList metadata и обложки;
- Jikan/MAL fallback для сопоставления;
- поиск аниме по кадру через trace.moe;
- `/anime`, `/top`, `/trending`, `/season`, `/subs`;
- `/providers` и `/scan` только для владельца `ADMIN_ID`;
- команды работают в ЛС, группах и супергруппах;
- один разрешённый канал `CHANNEL_ID`;
- автоматический выход из любых других каналов;
- общая рассылка каждого нового релиза во все зарегистрированные ЛС/группы/супергруппы;
- единый формат релиза и кнопка «Найти аниме» из `ANIME_SEARCH_URL`;
- AniList cover в публикации, если удалось сопоставить тайтл;
- дедупликация и baseline первого сканирования;
- SQLite по умолчанию, PostgreSQL можно подключить через `DATABASE_URL`;
- Dockerfile для BotHost/self-hosting.

## Формат релиза

```text
🌊 Новая серия
🎬 Название аниме
📺 Серия: 6
🎙 Озвучка/источник: AniLiberty
🆔 AniList: XXXXX
🔗 Источник релиза
```

Под сообщением: кнопка `Найти аниме`.

## Быстрый запуск

1. Заполнить `.env`.
2. Установить зависимости: `pip install -r requirements.txt`.
3. Запустить: `python main.py`.

Или собрать `Dockerfile`.
